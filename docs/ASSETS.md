# Asset provenance

| Asset | Source | Rights |
|---|---|---|
| `public/demo/*.jpg` (20 illustrations) | Drawn from code in `scripts/generate-demo-art.mjs` for this project | Original, no third-party material |
| Stickers (`src/lib/scene/stickers.ts`) | Vector paths written for this project | Original |
| Icons (`src/components/icon-data.ts`) | Lucide, https://lucide.dev | ISC license |
| Fonts | Bricolage Grotesque, DM Sans, Instrument Serif, Space Grotesk, Caveat, from Google Fonts | SIL Open Font License |
| Quote bank (`src/lib/ai/quotes.ts`) | Written for this project | Original |

The demo images are stylized illustrations, not photographs. To regenerate them, run `npm run art`.

The files in `references/` are your inspiration images. The app doesn't use or display them. Their ideas were adapted into an original design; see IMPLEMENTATION_NOTES.md.

Images added through Openverse come from third parties. Only CC0 and public-domain marked images are accepted. Each keeps its title, creator, license and source, shown under credits in the download dialog. Openverse is an index and can't guarantee rights, so check the source before commercial use.
